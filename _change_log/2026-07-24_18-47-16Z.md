Implemented via `registerMarkdownPostProcessor` — no parser hooks.

- `src/foldableEmbedsPostProcessor.ts`: strict `-` marker parse/strip on the embed span next-sibling text node (marker only when immediately after `]]` and followed by whitespace/EOL; `![[x]]-like` untouched), setIcon chevron injection, title click handler, async-load via tracked MutationObservers (disconnected on unload).
- `src/foldStateStore.ts`: in-memory session fold store; key includes source path, section locator, src, and per-occurrence index so same-note embeds fold independently.
- `src/main.ts`: stripped all sample-plugin scaffolding; lifecycle-only. `src/settings.ts` deleted (no settings in v1).
- `styles.css`: class-driven collapse (`.fen-folded`), forced-visible title bar, chevron rotation.
- `e2e/foldable-embeds.e2e.ts`: 8 tests vs real Obsidian 1.12.7 (fold/unfold, dash-strip, strict-negative, mode-switch persistence, same-note independence, heading/block-ref variants, body-actually-hidden).
- eslint scoped to `src/` (obsidianmd plugin ruleset no longer lints the Node e2e harness — also repaired a pre-existing red baseline).

Out of scope (follow-up tickets): Live Preview/editing mode, fold-all/expand-all commands.

Acceptance: build + lint clean; 11/11 e2e green.
